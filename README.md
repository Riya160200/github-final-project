# DevOps Capstone Project

## Project Overview
This project demonstrates Git and GitHub workflows, including repository documentation, branching, merging, pull requests, and a Bash script for calculating simple interest.

## Objectives
- Practice version control with Git and GitHub.
- Maintain standard open-source project documentation.
- Create and run a Bash script.
- Practice forking, merging branches, and inspecting repository branches.

## Technologies Used
- Git
- GitHub
- Bash
- awk

## Simple Interest Calculator
The `simple-interest.sh` script asks for the principal amount, annual rate of interest, and time period in years, then calculates simple interest.

Formula:

Simple Interest = (Principal × Rate × Time) / 100

## Usage
Run the script in a Bash-compatible terminal:

```bash
bash simple-interest.sh
```
